# Jotstead release specification

Build an independently implemented Notion-style personal workspace, branded Jotstead, with a generated original icon. User authorizes autonomous decisions, implementation, validation, and GitHub delivery in one run. Use public official Notion UI captures as reference. No access to a private logged-in reference; do not claim exact parity or a numerical similarity score.

Web plus desktop/mobile installable PWA share the same implementation and data. No native binaries or app store release. Next.js 16, React 19, Tiptap 3 and Node 24; single-owner SQLite server and filesystem attachments. Default bind loopback. Remote hosting requires a password and HTTPS. No subscription dependencies. Optional AI via configured compatible provider, never simulated.

Release: nested pages/favorites/trash/restore/search; rich editor with stable block IDs, slash commands, formatting, tasks, toggles, callouts, code, image/file attachment, tables, block movement and undo; icons/covers/themes/page width; row pages and typed database properties; saved table/board/gallery/list/calendar/timeline/chart views with shared data, filters/sorts; simple formulas, relations/rollups; version restore; loss-aware Markdown/CSV and full JSON import/export; offline draft recovery and conflict checks; private workspace authentication; explicit page publishing and forms; authenticated API and optional AI assistant. Add simple rule automation only if it can be verified. Exclude enterprise features, realtime team collaboration, binary file RAG, native apps, third party integrations, full Notion formula compatibility, and domain provisioning.

Persistence: versioned validated workspace JSON persisted transactionally to SQLite with revisions, retry identifiers and history. Never overwrite server changes silently. Show pending/saved/offline/conflict states. Cache offline drafts in IndexedDB. Recovery and exports always available. Backup includes uploads and DB; demonstrate restore to fresh storage. History is not a backup.

Safety limits: 5 MiB state, 20 MiB attachment, 2,000 pages, 100 properties per database, document depth 32. Limits protect resources, no paid unlock. Published page only that page's text and allowed attachment links; no private workspace payload. No unrestricted embeds or unsafe URL protocols. Upload files served as downloads except safe raster images. Formula parser never executes JavaScript.

Visual baseline: white/light gray, system sans fonts, sidebar 240 px, toolbar 45 px, document content 696 px, title 40 px. Public Notion references determine details; light, dark, narrow screen and interaction captures assessed separately. Standard icons from Phosphor; emoji page icons are editable user content like the reference.
