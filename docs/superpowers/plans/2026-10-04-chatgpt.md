# ChatGPT Integration Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans task by task.

**Goal:** Connect Jotstead and ChatGPT through identity, scoped AI and a personal plugin.
**Architecture:** Server-only OAuth/vault; local sessions independent of AI. Shared structured page metadata and a scoped MCP runtime reuse SQLite revision protection. React components expose consent and explicit context.
**Tech Stack:** Node 24, Next 16, SQLite, jose, MCP SDK, esbuild, Vitest.
**Spec:** docs/superpowers/specs/2026-10-04-chatgpt.md

## Global Constraints
- Personal local workspace; web and PWA, no remote hosting or native binary.
- No credentials in browser storage, logs, source control, exports or ordinary backups.
- AI consent is separate from identity; quota cannot lock notes.
- Only selected context; no automatic ChatGPT history/project/memory import.
- Plugin access disabled until the owner enables page scope and writes separately.

## Review Focus
- Owner binding during competing callbacks; another identity must never replace credentials.
- Stale/disconnected OAuth callbacks and cookie mismatch must fail before code exchange.
- Refresh rotation across processes and disconnect while refresh is in flight.
- Partial SSE failures must remain unsaveable; context must exclude unselected pages.
- Plugin scope escape via parent/descendant/database mutation and untrusted preview content.
