# Clean UI implementation plan
Goal: deliver a calm, reliable workspace with content above controls.
Architecture: preserve Next.js/Tiptap/sqlite/local draft architecture; introduce Home and shared property presentation; revise existing navigation and database components; single coordinated workspace stylesheet.
Tech Stack: Next 16, React 19, TypeScript, Tiptap 3, Vitest/happy-dom, CUA browser verification.
Spec: docs/superpowers/specs/2026-10-04-clean-ui.md
Global Constraints: preserve private data; no new dependency needed; no invented live OAuth capability; user has delegated decisions and authorized GitHub delivery; functional regressions test-first; screenshots use disposable data.
