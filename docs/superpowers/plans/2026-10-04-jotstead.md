# Jotstead Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox syntax for tracking.

**Goal:** Deliver a usable self-hosted Notion-style workspace and installable PWA, with durable real data and reviewed browser evidence.

**Architecture:** One Next.js application serves a private single-owner workspace, typed API, SQLite revisions, and filesystem attachments. React editor/database features consume a validated canonical Workspace; client saves are serialized and optimistic, with offline drafts and explicit conflict recovery. Public output is isolated from private state.

**Tech Stack:** Node 24, Next.js 16, React 19, TypeScript, Tiptap 3, Phosphor icons, Zod, SQLite, Vitest.

**Spec:** docs/SPEC.md; original BUILD_PLAN.md remains roadmap.

## Global Constraints
- Web plus desktop/mobile installable PWA share the same implementation and data.
- No native binaries or app store release.
- Never overwrite server changes silently.
- No subscription dependencies.
- Formula parser never executes JavaScript.
- Safety limits: 5 MiB state, 20 MiB attachment, 2,000 pages, 100 properties per database, document depth 32.

## Review Focus
- Concurrent browser saves must conflict and preserve local draft. Task 1 revision test, Task 2 recovery probe.
- Moving a page below its own descendant must be rejected. Task 1 cycle test.
- Invalid import must leave existing state unchanged. Task 1 schema test, Task 5 browser probe.
- Publishing a page must not expose private pages or unsafe attachments. Task 4 projection/auth test.
- Offline edit and reload must preserve draft and reconnect safely. Task 2 IndexedDB/manual offline probe.
