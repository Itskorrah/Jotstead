# Jotstead + ChatGPT

Approved scope: a personal local workspace using ChatGPT identity, separately consented ChatGPT plan inference, a local plugin, selected saves, shared project briefs and a contextual page preview. Web and installable PWA remain the supported clients. Claude, Gemini, remote hosting and automatic ChatGPT history/project/memory import are deferred.

Use documented OpenAI dynamic registration with loopback callback, PKCE, state, nonce and verified ID tokens. Bind the existing workspace to the first verified issuer/subject after a SQLite backup; different identities cannot inherit it. Sessions are local, renewable by signing in, independent of provider quota. Tokens stay encrypted in protected runtime storage, excluded from exports and ordinary backups. Identity-only authorization never silently enables inference. Owner sign-out revokes the local session; disconnect separately attempts remote revocation and clears provider credentials.

AI receives only explicitly selected live pages. Discover permitted models; request Responses API streams with store:false. A partial response cannot be saved as completed. Handle quota, declined sharing, unavailable models and interrupted streams visibly. Never automatically switch to a paid API key.

Shared briefs contain goals, preferences, decisions, next actions and an optional source chat URL. Saves and plugin updates require a current revision and mutation identifier. Page scopes and write permission are owner-controlled and disabled by default for the personal plugin. Local stdio is a trusted installed-client capability, not a public network endpoint. UI resources use the MCP Apps bridge with safe text rendering; host support varies.

Complete automated security/protocol/regression checks, production build, real HTTP and browser desktop/mobile verification, independent review and GitHub delivery. Live OpenAI consent and native host plugin loading need the user's interactive login and a supporting host; do not simulate or claim those occurred.
